## Sobre mim

<imagem alinhar="esquerda" fonte="ativos/cérebro.png" alt="Cérebro" largura="175" estilo="margem direita: 24px;">

Estudante de Engenharia de Software na **Universidade de Vassouras**, segundo período, focado em construir uma base sólida no desenvolvimento fullstack. Gosto de entender como as coisas funcionam por baixo dos panos — não só copiar código, mas saber **por que** uma diversidade. Trabalho principemente com **JavaScript**, tanto sem frente quanto sem costas.

**Como penso sobre aprender:** prefiro construir projetos reais a ficar só tutorial auxiliar. Erro, debugo, entendendo — e guardo é melhor do que qualquer slide.

## Foco no momento
<imagem alinhar="certo" fonte="ativos/flame.png" alt="Chama" largura="155" estilo="margem escerta: 24px; margem inferior: 8px;">

No momento, meu foco principal está em construir uma base sólida em JavaScript, explorando a fundo a manipulação de DOM, integração com APIs e lógica associada antes de avançar para frameworks. Paralelamente, estou mesclando no back-end com Node.js para entrar como funções rotas, bancos de dados e autenticação, que são os pilares de um sistema real. Além disso, dediquei a transformar a organização e documentação em um hábito, acreditando que código limpo e bem explicado não é apenas um luxo, mas um diferenteessencial para qualificar o desenvolvedor.

## Projetos em destaque

[![caixa sombreada](https://img.shields.io/badge/shady--box-repositório-black?style=for-the-badge&logo=github&logoColor=white)](https://github.com/gabrielsrfm/shady-box)

Gerador de *caixa-sombra* interativo e responsivo. Desenvolvimento para praticar a **manipulação de DOM com JavaScript** e layouts complexos utilizando **Flexbox e Grau**. Ideal para quem quer visualizar sombras CSS em tempo real.

[![Trabalho-de-Desenvolvimento-Web](https://img.shields.io/badge/Trabalho--Dev--Web-repositório-black?style=for-the-badge&logo=github&logoColor=white)](https://github.com/gabrielsrfm/Trabalho-de-Desenvolvimento-web)

Trabalho Acadêmico (1o Período | Univassouras) focado em estrutura semântica com **HTML5** e estilização avançada com **CSS3**. O projeto aplica conceitos fundamentais de design responsivo e usabilidade. Desenvolvimento em colaboração com [Leosouza-devv](https://github.com/Leosouza-devv).

[![Gerador-de-Senhas](https://img.shields.io/badge/Gerador--de--Senhas-repositório-black?style=for-the-badge&logo=github&logoColor=white)](https://github.com/gabrielsrfm/Gerador-de-Senhas)

Gerador de senhas aleatórias e segmentos. Desenvolvimento para praticar **lógica com JavaScript** e manipulação de **CASA**. Permite configurar comprimento, tipos de caracteres e exibe um indicador de força da senha em tempo real.

[![Gerador-de-Sabedoria](https://img.shields.io/badge/Gerador--de--Sabedoria-repositório-black?style=for-the-badge&logo=github&logoColor=white)](https://github.com/gabrielsrfm/gerador-de-sabedoria)

Aplicação web que consome a API pública quotable.io para exibir frases inspiradoras aleatórias. Desenvolvido para praticar consumo de APIs com Fetch e manipulação de DOM. Exibe autor e categoria de cada frase, com fallback automático para frases locais caso a API é indispensável.
